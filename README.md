## 📌 Featured Projects

### ⭐ [Machine Learning: Theory to Code](https://github.com/Muhammadfaheem8988/machine_learning-theory-to-code)
A growing series of Jupyter notebooks based on my handwritten notes, connecting ML concepts and mathematical intuition with visualizations and Python implementations.

### ⭐ [HeatGuard Alerts](https://github.com/Muhammadfaheem8988/HeatGuard)
A FortyGuard Hackathon 2026 demonstration combining heat and public-health data to visualize and rank heat vulnerability in Maricopa County. Built with Python, Streamlit, Folium, and Gemini-generated simulated alerts.

### ⭐ [ML Interview Questions — 30-Day Challenge](https://github.com/Muhammadfaheem8988/ml-interview-questions-challenge)
A collection of 150 multiple-choice questions and explanations covering classical machine learning, statistics, and data science fundamentals.

### ⭐ [FinPak — Smart Finance Tracker](https://github.com/finpak-ai/finpak-a-smart-finance-tracker)
A personal finance project exploring spending trends and ML-based predictions for overspending, savings, and financial health.

### ⭐ [Speech-to-Text & Speaker Diarization](https://github.com/Muhammadfaheem8988/fastapi-transcriber-and-Speakers-Diarization)
A FastAPI backend project for audio transcription and speaker identification using AssemblyAI.

### ⭐ [Superstore Sales Analysis](https://github.com/Muhammadfaheem8988/Superstore-Sales-Data-Analysis)
Data analysis using Python, Pandas, NumPy, and visualizations to explore sales insights.
